# Практическое задание 8 – работа с сетью

Приложение продолжает задание 6. Открывайте в Android Studio папку `hw4-showcase/`. Для сборки нужны JDK 17 или новее и Android SDK 35.

Каталог загружается с `http://185.103.109.134/catalog` через Retrofit и Gson. DTO преобразуются в доменную модель с ID, названием, описанием, категорией и адресом иконки. Экран показывает загрузку, ошибку с повторной попыткой и пустой каталог. HTTP разрешён только для адреса учебного сервера.

В `CatalogApi` также подготовлен GET `/{id}`. Экран подробностей по условию пока не подключён к этому запросу: по нажатию остаётся прежняя демонстрационная карточка. На момент проверки сервер возвращал 404 для ID, полученного из каталога, поэтому формат подробного ответа ещё нельзя проверить; метод возвращает JSON-объект.

Для проверки:

```sh
cd hw4-showcase
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

На устройстве проверьте загрузку списка с доступным интернетом и кнопку повтора при отсутствии сети. Проверка тестов использует локальный тестовый сервер и не зависит от учебного сервера.
